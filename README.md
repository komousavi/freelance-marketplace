Freelance Marketplace

Project Overview
Freelance Marketplace is a web application that connects clients with freelancers. Clients can publish projects, and freelancers can browse available projects and submit proposals.

Main Actors
- Client: Publishes projects and reviews proposals.
- Freelancer: Creates a profile, browses projects, and submits proposals.
- Administrator: Manages the platform.

Technology Stack
- Frontend: Flutter 
- Backend: Django
- Database: SQLite
