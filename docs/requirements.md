2.Functional Requirements

FR-01 — User Registration
The system shall allow users to create a new account by providing the required registration information.

FR-02 — User Role Selection
The system shall allow users to select a role as either a freelancer or an employer.

FR-03 — Freelancer Profile Management
The system shall allow freelancers to create and update their profiles, including personal descriptions, skills, work experience, and educational background.

FR-04 — Portfolio Management
The system shall allow freelancers to add portfolio items to their profiles and edit or delete existing portfolio items.

FR-05 — Project Listing
The system shall allow freelancers to view projects published by employers.

FR-06 — Project Search
The system shall allow freelancers to search for projects using criteria such as project title and required skills.

FR-07 — Proposal Submission
The system shall allow freelancers to submit proposals for projects they are interested in.

FR-08 — Proposal Review
The system shall allow employers to view and review proposals submitted for their projects.

FR-09 — Messaging
The system shall provide a messaging feature that allows freelancers and employers to send and receive messages related to potential or ongoing collaborations.

FR-10 — Freelancer Selection
The system shall allow employers to select a freelancer from among the applicants who have submitted proposals for a specific project.

FR-11 — Project Posting
The system shall allow employers to create and publish new projects by providing details such as the project title, description, required skills, and budget.

FR-12 — Project Management
The system shall allow employers to edit or delete projects they have created.

FR-13 — Employer Proposal Management
The system shall allow employers to accept or reject proposals submitted for their projects.

3.Non-Functional Requirements

NFR-01 — Role-Based Access Control
The system shall restrict users' access to information and functionalities based on their assigned roles, such as freelancer or employer.

NFR-02 — Usability
The system's user interface shall be designed to enable users to perform the main system operations without requiring specialized training.

NFR-03 — Reliability
The system shall perform its core functions reliably under normal operating conditions and handle unexpected errors without causing system failure.

NFR-04 — Data Integrity
The system shall validate input data and enforce database constraints to prevent the storage of incomplete or inconsistent data.

NFR-05 — Maintainability
The software shall follow a modular design that allows individual components to be modified and extended with minimal impact on other components.
